About Easy Game

Easy Game is a modern, responsive, client-side online quiz examination platform engineered to help undergraduate engineering students practice core technical subjects, self-assess their concepts, and prepare for placement tests and competitive exams.

🎯 Purpose of Easy Game

In modern computer science and data science education, continuous assessment and active recall are fundamental to mastering abstract algorithmic concepts, systems programming, and database theory.

Easy Game addresses this need by providing an instant, zero-latency testing interface where students can test their knowledge without requiring account creation, server setup, or database connectivity. Everything executes locally in the web browser, ensuring lightning-fast performance and total offline accessibility.

🚀 How It Works

1

Select a Subject

Choose from 8 core engineering disciplines including C Programming, Python, Java, DBMS, OS, Computer Networks, Data Structures, and DAA.

2

Select Difficulty

Pick Easy, Medium, or Hard difficulty to tailor question complexity to your current study stage.

3

Choose Number of Questions

Select either 5 questions (5-minute test), 10 questions (10-minute test), or 15 questions (15-minute test).

4

Enter Your Name

Provide your name to personalize your score report and record your achievement on the platform leaderboard.

5

Start the Quiz

The platform executes Fisher-Yates randomization to shuffle questions and answer options, preventing memorization bias.

6

Answer Before the Timer Ends

Navigate through questions freely, revise answers, and monitor the countdown clock with live warning indicators.

7

Submit and View Your Result

Receive an instant score report with percentage accuracy, circular progress ring, and an in-depth answer review with academic explanations.

⚙️ Technologies Used

Easy Game was built entirely using vanilla standard web technologies without external dependencies, libraries, or server backends:

🌐
HTML5
Semantic document markup (<header>, <nav>, <main>, <section>, <article>, <footer>) ensuring accessibility and clean structure.
🎨
CSS3
Custom CSS Variables, Flexbox, CSS Grid, media queries, smooth animations, and dual light/dark themes without CSS frameworks.
⚡
Vanilla JavaScript
Modern ES6+ algorithms for question randomization, countdown timers, state management, and real-time DOM updates without jQuery or React.
💾
LocalStorage API
Persistent browser client-side storage for active quiz state, student preferences, theme settings, and leaderboard historical rankings.
Pure Frontend Architecture: This application requires no Node.js backend, no Python server, no SQL database, and no internet API calls. The entire application runs natively in any modern browser by simply opening index.html.
